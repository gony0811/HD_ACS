# WALL A 코봇 AREA 기하 검토

> **2026-09-21 갱신:** 아래의 층 바닥부터 1440 mm 높이 밴드를 실제 코봇 도달 한계로 보지 않는다. 1440 × 1440 mm는 AREA 한 개의 최대 크기다. 전체 높이의 용접선 후보를 포함한 최신 AutoCAD 검토도는 `drawing/area-preview/full-coverage/WALL_A_cobot_full_coverage.dwg`이다. 기존 밴드 도면과 수량 표는 과거 가정의 기록이며, 최신 전체 높이 계획의 수량으로 사용하지 않는다.

> 검토용 계산. 선창 실측 치수는 사용자 제공값이며, DXF 원점 정합과 로봇 도달범위는 현장 확인 전이다. 원본 도면은 외부 공유 금지.

## 입력 치수 (mm)

| 항목 | 값 |
|---|---:|
| 선창 길이 L | 30960 |
| 최대 폭 W | 17277.6 |
| 전체 높이 H | 12957.6 |
| 하부 챔퍼 높이 / 각도 | 3735.3 / 45° |
| 상부 챔퍼 높이 / 각도 | 2655.3 / 45° |
| 층 바닥 z | 0, 3630, 6630, 10530 |
| 천장 z | 12957.6 |
| AREA 축별 최대 크기 | 1440 × 1440 |

층간 높이는 차례로 3630, 3000, 3900, 2427.6 mm다. 수직벽 높이는 `12957.6 − 3735.3 − 2655.3 = 6567` mm다. W가 챔퍼 사이의 최대 폭일 때, 바닥 폭은 `17277.6 − 2×3735.3 = 9807` mm, 천장 폭은 `17277.6 − 2×2655.3 = 11967` mm다.

## DXF 좌표 대응 (추정)

`drawing/2D도면/WALL A.dxf`의 Steel Wall 팔각형 외곽 범위는 x=16320.087~34425.087, y=9637.6~23422.6 mm다. 외곽 중심은 (25372.587, 16530.1)이다. 막 영역의 경계상자도 같은 중심을 갖는다. 이 공통 중심에 사용자 제공 W/H를 배치하면 내부 바닥은 **DXF y=10051.3**, 천장은 **y=23008.9**가 된다. 외곽선과 내부 선창 경계의 각 방향 차이는 413.7 mm다.

이는 **중심 일치 가정에 따른 기하학적 대응값**이며, 실제 바닥 기준선으로 확정된 좌표는 아니다. 기존 인수인계의 y=9137.6은 Steel Wall 격자선 끝점이며 외곽선 바닥도 아니다. 선창 전역 z와 DXF y의 대응은 이 가정에서만 `DXF y = 10051.3 + z`다.

| 위치 | z | 추정 DXF y |
|---|---:|---:|
| 바닥 | 0 | 10051.3 |
| 1단 바닥 | 3630 | 13681.3 |
| 하부 챔퍼 상단 | 3735.3 | 13786.6 |
| 2단 바닥 | 6630 | 16681.3 |
| 수직벽 상단 | 10302.3 | 20353.6 |
| 3단 바닥 | 10530 | 20581.3 |
| 천장 | 12957.6 | 23008.9 |

## 층별 AREA 배치 (검토용)

사용자 결정에 따라 **바닥+100 mm 오프셋은 사용하지 않는다.** 각 층 바닥부터 1440 mm 높이의 작업 밴드를 임시 적용하며, WALL A 최하단 수평 용접선(DXF y=10215.1)은 검사 대상에서 제외한다. `tools/build_wall_a_level_areas.py`는 기존 DXF 기반 720 mm 직선 작업, 최하단 수직선의 짧은 시작 부분, 긴 용접선의 CROSS3/4 교차점 후보를 묶어 팔각형 내부에 들어가는 사각 AREA를 만든다. 면 위 검사 범위의 배치이며 실제 로봇 정차점이나 도달 검증은 아니다.

작업방법은 `LINE`(수직/수평 직선), `CROSS3`(3판·3갈래 교차), `CROSS4`(4판·4갈래 교차)로 구분한다. CSV는 AREA별 각 방법의 개수를, JSON은 작업별 방법과 직선 방향을 기록한다. 현재 CROSS3/4는 **DXF 용접선의 연결 갈래 수로 찾은 후보**다. 판 수 자체는 별도의 판 경계 확인 없이 확정하지 않는다.

| 층 | 추정 DXF 작업 밴드 y | 직선/교차점 후보 | AREA 후보 |
|---|---:|---:|---:|
| 0단 | 10051.3~11491.3 | 26 | 8 |
| 1단 | 13681.3~15121.3 | 39 | 14 |
| 2단 | 16681.3~18121.3 | 70 | 14 |
| 3단 | 20581.3~22021.3 | 34 | 12 |

이 배치는 검토용 탐욕적 작업 묶음이며 **AREA 개수의 전역 최적해는 보장하지 않는다.** AREA 너비·높이는 각각 최대 1440 mm이고, 챔퍼 안쪽에 들어가도록 일부는 더 작다. 도면은 `drawing/area-preview/wall-a-level-areas.svg`, 전체 높이에서 도달 밴드와 공백은 `wall-a-level-reach-overview.svg`, 좌표·작업 대응은 같은 폴더의 CSV/JSON에 있다. 네 밴드 바깥에 남는 높이는 이 가정만으로 검사할 수 없다. 운영 등록 전에는 DXF 내부 바닥 y=10051.3의 기준점, 각 층의 실제 정차 높이, 로봇 승강 범위를 확인해야 한다.

판 경계 비교는 `wall-a-level-areas-toggle.html`에서 원본 `KC-2B Membrane Sheet UM`의 LINE/LWPOLYLINE 선을 켜고 끌 수 있다. `wall-a-level-areas-with-sheet-lines.svg`는 경계 후보를 켠 정적 그림이다. 이 레이어에는 용접 작업선과 겹치는 선 및 짧은 상세선이 함께 있어, 표시만으로 각 판의 실제 경계를 확정하지 않는다. ELLIPSE 코너 형상은 이 직선 오버레이에서 제외한다.

0단의 최하단 **수평** 용접선(DXF y=10215.1)만 제외했다. 같은 점에서 위로 이어지는 주요 수직 용접선 4개의 하단 부분(y=10215.1~10410.126, 약 195 mm)은 별도 짧은 작업 후보로 포함한다. 따라서 이 수직선에는 별도의 높이 제외 기준을 두지 않았다. 수평선과 만나는 정확한 시작점의 실제 검사 가능 여부는 현장 확인 대상이다.
