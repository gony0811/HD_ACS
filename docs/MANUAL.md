# HD_ACS 운영 매뉴얼 — 영역 기반 검사 워크플로우

> 대상: 운영자 · 현장 엔지니어. UI = HD.Acs.UI("영역·작업 관리" 패널) 기준.
> 계층: **벽면(Wall) → 영역(Area) → 검사 작업(Task)** [SPEC PHASE2 v2].
> 관련 문서: 좌표 규약 [TANK_WALL_LAYOUT §6], 스키마 [DB_SCHEMA], 계약 [SPEC_PHASE2_ACS].

## 0. 사전 준비 (층별 1회)
1. **맵(층) 등록·활성화** — `ref.map`에 tank/level별 활성 맵.
2. **도면→맵 캘리브레이션(T_W_D)** — "캘리브레이션" 화면에서 기준점 캡처 후 solve(맵버전 일치).
   유효 T_W_D가 없으면 미션 생성이 거부된다.

## 1. 벽면(Wall) 등록 — 레지스트리(코드·설명)
- "① 벽면 등록"에서 `Lv`(층), `벽면코드`(예 SM/PM/A [TANK_WALL_LAYOUT §2]), `설명`을 입력 → **벽면 등록**.
- 벽면은 `(tank, level, wall_code)` 단위. 같은 코드라도 층마다 등록한다. 재등록 시 갱신(upsert).
- **정차각·법선은 입력하지 않는다.** 정차각은 영역·작업 기하에서 자동 산출되고, 코봇 툴 자세는 HD_AMR이 wall_code 티칭으로 처리한다(벽면 등록은 티칭 조회 키·영역 FK 게이트 역할).

## 2. 영역(Area) 등록 — AMR 1회 정차 범위
- "② 영역 등록"에서 `Lv`, `벽면`(등록된 벽면 드롭다운), `이름`(층·벽면 내 유일), 경계 `min/max (X,Y)`(도면 m)를 입력 → **영역 등록**.
- 경계는 축정렬 사각형(`minX<maxX`, `minY<maxY`). 사각형 **중앙이 기본 정차 위치**.
- **정차각 자동 산출 규율:** 정차각은 "정차 위치 → 영역 seam 점들의 중심" 방향으로 자동 계산된다. 따라서 영역을 **정차 지점(바닥) ↔ seam(벽)을 모두 포함**하도록, 즉 seam이 사각형 중앙이 아니라 **벽쪽 가장자리**에 오게 그린다. 안 되면 정차각이 산출되지 않아(§4) 미션 생성이 거부된다.
- 필요 시 정차 pose 수동 오버라이드(x/y/θ) 가능. `station_theta`를 주면 자동 산출보다 우선.
- 등록된 벽면이 아니면 400(먼저 벽면 등록). 같은 (층·벽면) 내 이름 중복은 409.

## 3. 검사 작업(Task) 등록 — 영역 내 N개
- 영역 선택 후 "③ 검사 작업 등록"에서 시작/끝점 `(x,y,z)`(도면 m)·DXF·프로파일 입력 → **작업 등록**.
- 시작/끝점은 영역 경계 **내부**여야 한다(벗어나면 400). z는 자유(챔퍼·벽 높이).
- 작업 1개 = TASK 1개 = actionId 1개 = 결과 1행.

## 4. 미션 생성 (generate-from-areas)
- **미션 생성** 버튼 → 시나리오 tank의 영역/작업을 스테이션·TASK로 변환.
- 사전 검증(하나라도 실패하면 아무것도 생성 안 함, 400 + reasons):
  - 등장 층별 **유효 T_W_D** 존재.
  - 각 영역 **정차각 산출 가능**(`station_theta ?? atan2(정차→seam 중심)`). 정차 위치와 seam 중심이 일치(degenerate)하고 `station_theta`도 없으면 실패.
  - 작업 0개 영역은 조용히 skipped(생성 대상 제외).
- 결과: 영역=STATION 노드(anchorGroup), 작업=검사 TASK. 정차각·좌표는 T_W_D로 맵 좌표 변환.

## 5. 실행·모니터링
- 시나리오 Run 시작 → HD_AMR이 정차→검사 실행. state 보고로 진행률/결과 갱신.
- 발행 payload는 `seamStartW/EndW`·`drawingPos`·`params`(wallNormalW 없음). 툴 자세는 로봇 티칭.

## 6. 문제 해결
| 증상 | 원인/조치 |
|---|---|
| 영역 등록 400 "등록된 벽면이 아닙니다" | 해당 (층·벽면) 미등록 → 1단계 벽면 등록 |
| 영역 등록 409 | 같은 (층·벽면) 내 동일 이름 존재 → 이름 변경 |
| 작업 등록 400 "경계를 벗어났습니다" | 시작/끝점이 영역 사각형 밖 → 좌표 또는 영역 경계 조정 |
| 미션 생성 400 "유효 T_W_D 없음" | 해당 층 캘리브레이션 필요(0단계) |
| 미션 생성 400 "정차각 자동 산출 불가" | 정차 위치와 seam 중심이 일치(seam이 영역 중앙) → 영역을 벽쪽으로 확장해 seam이 가장자리에 오게 하거나 `station_theta` 지정 |
