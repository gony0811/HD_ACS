# 실험실(준-정육면체) 평가 가이드 — 환경 셋업 + FMEA 검증 매트릭스

> **목적**: 팔각 선창 실물 없이 1단 정육면체 실험실(벽면 멤브레인 목업)에서 ACS↔AMR 통합 평가를 수행하고,
> S/W FMEA(`과제 위험성 평가 시트_FMEA_20260827.xlsx` — SW-01~34) 항목을 최대한 검증한다.
> **코드 변경 없음** — 기존 파라메트릭 지오메트리로 준-정육면체를 표현한다(§1.2).
> 작성 2026-08-31. 사전 E2E 검증 완료(§1.6).

## 1. 환경 셋업 절차

### 1.1 실측

- 실험실 내부 치수: 길이 L × 폭 W × 높이 H (m, 로봇 주행 가능 영역 기준)
- 멤브레인 목업: 설치된 벽면(어느 벽), 벽면-로컬 (u,v) 위치·크기, 용접라인 시작/끝 (u,v)
  - u = 벽을 정면으로 봤을 때 좌하단 원점 기준 수평(m), v = 수직(m) — 규약은 TANK_WALL_LAYOUT §6

### 1.2 준-정육면체 파라미터 (챔퍼 극소화)

지오메트리 검증이 챔퍼 각 (0°,90°)·높이 >0을 요구하므로 **2cm 챔퍼**로 근사한다 (θ=45° → 수평 run = 높이):

| 파라미터 | 값 | 비고 |
|---|---|---|
| lengthL | **L** (실측) | |
| wFloor | **W − 0.04** | 전폭 B = wFloor + 2×(hLow/tanθ) = W 가 되도록 역산 |
| thetaLowDeg / thetaUpDeg | 45 | |
| hLow / hUp | 0.02 | 2cm 스트립 — 영역 등록 안 함 |
| hWall | **H − 0.04** | 전체높이 = hLow+hWall+hUp = H |
| levelZ | [0] | 1층 단일 |

→ 결과: SM/PM(장측벽 L×(H−0.04)) · F/A(단측벽 W×H) · B/T(바닥/천장) + 2cm 스트립 4면.
**멤브레인 목업 벽 = SM/PM/F/A 중 해당 벽**에 영역·용접라인을 등록한다.

### 1.3 데이터 등록 (UI 또는 REST — :5199)

```
① POST /api/tanks/LAB/geometry     (§1.2 파라미터 — UI: 파일 ▸ 새 프로젝트)
② POST /api/areas                  멤브레인 목업 = 영역(4점 u,v + stationStandoffM)
③ POST /api/areas/{id}/tasks       용접라인(시작/끝 u,v, seamType=LINE — POLYLINE은 400)
④ POST /api/scenarios + PUT …/areas  시나리오(부분 검사 계획 — 대상 0개=전체)
⑤ ref.map 행: INSERT INTO ref.map (map_id,tank_id,level,name,version) VALUES ('LAB-L1','LAB',1,'실험실 1층',1)
```

주의: `stationStandoffM`(정차 이격, 기본 0.8m)은 **좁은 실험실에서는 코봇 리치·벽 여유에 맞게 조정** — N10 미확정 상태이므로 실측으로 적정값을 찾는 것 자체가 평가 항목.

### 1.4 로봇·네트워크

- `ref.robot`의 manufacturer/serial = **실 HD_AMR의 MQTT 토픽 요소와 일치** 필수 (현재 HHI/AMR-01 — 실기 값 확인 후 갱신)
- MQTT 브로커(:1883)를 로봇이 접속 가능한 IP로 바인딩 + 방화벽 허용
- ⚠ **ACS REST(:5199)는 현재 localhost 바인딩** — 같은 PC의 UI만 접속 가능(SW-34 참조, 다중 PC 모니터링은 보완 필요)

### 1.5 현장 T_W_D 캘리브레이션 (§1.3의 placeholder 항등 변환 교체)

1. 로봇을 도면상 위치를 아는 지점(벽 모서리 등)에 정차 → UI 캘리브레이션 패널에서 도면 좌표 입력+캡처
2. 2~3점 반복 — **점 간 거리 최대화**(실험실 대각 양끝), 3점째=잔차 검증
3. Solve → RMS ≤ 5cm 확인(초과 시 경고 — 오등록 의심)
4. **수동 이동(goto)으로 정합 확인**: 층 L1 선택 → 바닥 그리드 클릭 → 실물 도착 위치를 줄자로 대조 (SW-02 실측)

### 1.6 사전 E2E 검증 결과 (2026-08-31, 플레이스홀더 5×5×3m)

- LAB 지오메트리 등록 → **10면 정상 생성**(수직벽 2.96m, 챔퍼 2.8cm 스트립)
- SM 벽 멤브레인 목업 영역(MOCK-01)+용접라인 2개(MW1/MW2) 등록 → run 시작 → **큐 전개 좌표가 수기 계산과 정확 일치**
  (정차점 = 영역 중심 + 법선 0.8m 이격 = (−0.5, −1.7), θ=−π/2)
- 실측 치수 확보 시 §1.2 값으로 재등록만 하면 됨 (LAB 데이터는 DB에 유지)
