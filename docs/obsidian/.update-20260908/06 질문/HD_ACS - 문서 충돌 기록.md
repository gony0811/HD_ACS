# 문서 충돌 기록

## 2026-09-08 좌표 표기 차이

기존 코드·사양의 x=길이/y=폭(+좌현) 설명과, 현장 메모의 X 원점 8.64/Y 원점 15.48·좌현(-)/우현(+)는 축 순서·부호 대응 확인이 필요합니다. 한쪽을 오류로 확정하지 않고 별도 좌표계 기록으로 보존합니다.

추가 점은 원문에서 1.76-8.64=-5.74로 기록됐지만 재계산은 -6.88입니다. 원문과 재계산 값을 병기하고 실제 적용값은 확인 필요로 남겼습니다.

P2 ‘선수/좌현’과 보정 y=-0.42의 관계도 확인 필요합니다. [[HD_ACS - L2 도면 SLAM 캘리브레이션]]에 실제 수치를 유지했습니다.


오래된 설명을 삭제해 이력을 지우지 않고 현재 기준과 구분합니다.

| 충돌 | 현재 읽는 기준 | 후속 조치 |
