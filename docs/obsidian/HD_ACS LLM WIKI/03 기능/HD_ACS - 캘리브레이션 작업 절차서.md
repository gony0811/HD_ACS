# 캘리브레이션 작업 절차서

기준일: 2026-09-08. 현재 코드의 축·변환·저장 동작을 확인하여 작성한 작업 절차입니다. 현장 검증 완료를 의미하지 않습니다. 자동 축 진단·승인 마법사는 제안이며 현재 구현 기능과 구분합니다.

## 1. ACS 좌표 기준 — 코드 확인 결과

| 항목 | 현재 ACS 기준 |
|---|---|
| +X / −X | 선수 F / 선미 A |
| +Y / −Y | 좌현 P / 우현 S |
| +Z | 위쪽. 아래쪽은 Z 감소 |
| 선창 바닥 중심 | (Ox, Oy, 0). Ox=OriginOx, Oy=OriginOy이며 기본값은 각각 0 |
| 바닥 / 층 높이 | 선창 바닥 z=0; 층 n의 주행 평면 z=LevelZ[n−1] |
| 길이·폭·높이 | m |
| 평면 방향 | +X 기준, 위에서 내려다볼 때 반시계가 양수 |
| 각도 예 | 0° 선수, +90° 좌현, ±180° 선미, −90° 우현 |
| API 각도 | rad. 수동 좌표 이동 UI의 방향 입력은 °를 rad로 변환 |

**좌표 부호는 선창 중심을 기준으로 판단합니다.** 선수측은 X>Ox, 선미측은 X<Ox, 좌현측은 Y>Oy, 우현측은 Y<Oy입니다. Ox/Oy가 0일 때만 절대 좌표의 양수·음수와 같습니다. 앞선 “원점은 항상 바닥 중심 (0,0)” 설명은 기본 설정에서만 맞습니다.

실제 형상 코드: F면 X=Ox+L/2, A면 X=Ox−L/2. PM은 Y=Oy+B/2, SM은 Y=Oy−B/2이며 B는 수직벽 구간 폭입니다. 경사면 때문에 층별 폭은 달라질 수 있으므로 전체 폭을 모든 층에 적용하지 않습니다. 화면의 좌우는 카메라에 따라 바뀌며 선수·좌현의 기준은 변하지 않습니다.

벽면 로컬 u/v는 위의 전역 X/Y와 다릅니다. 로컬 입력은 P=P0+uU+vV로 전역 위치로 바꿉니다. 경사면 거리나 전개도 u/v를 캘리브레이션 X/Y에 그대로 입력하지 않습니다.

## 2. 좌표계와 책임 분리

CAD 원본 또는 현장 실측 → ACS 전역 도면 좌표 → AMR 맵 좌표 순서로 처리합니다.

- 첫 단계: 측정 기준점, 축 방향·부호, 단위를 해석하여 ACS 좌표로 정규화합니다.
- 둘째 단계: 같은 물리적 기준점의 ACS 좌표와 AMR 보고 좌표로 층별 T_W_D를 계산합니다.
- AMR 맵의 원점·축을 ACS와 똑같이 바꿀 필요는 없습니다.
- AMR 보고 X/Y는 해당 mapId의 원본 값 그대로 기록합니다. 임의 축 교환이나 90° 보정을 중복 적용하지 않습니다.

현재 변환은 map=R(yaw)·drawing+t, drawing=R(−yaw)·(map−t)입니다. 방향은 mapTheta=drawingTheta+yaw, drawingTheta=mapTheta−yaw로 정규화합니다. T_W_D는 회전·평행이동만 지원하며 축척·반사·기울어진 측정축은 보정하지 않습니다.

## 3. 작업 전 준비

1. 프로젝트/tankId, 대상 층, 로봇 ID, mapId, 현재 맵 버전을 기록합니다.
2. 선창의 L, 층 높이, 해당 높이의 폭, Ox/Oy를 현재 프로젝트와 대조합니다. 크기만 알아서는 축·원점이 정해지지 않습니다.
3. 현장에 선수·선미·좌현·우현 표식을 확인하고 작업도면에 화살표를 그립니다.
4. 기존 기준점 목록과 적용 T_W_D(tx,ty,yaw,버전)를 백업·기록합니다.
5. 자동 작업이 진행 중이지 않은 상태에서 캘리브레이션합니다. 계산은 현재 코드에서 즉시 저장되므로 독립 검증 전 자동 운전을 재개하지 않습니다.
6. 적용할 위치·방향 오차 허용값을 작업 요구와 측정 정밀도에 따라 미리 정합니다.

## 4. CAD·줄자 실측값을 ACS 좌표로 정리

측정원점 O의 ACS 위치=(X0,Y0), 측정축 단위벡터 e1/e2, 단위 환산 s를 기록합니다.

ACS 위치 = O + s·a·e1 + s·b·e2

a/b는 측정원점에서의 좌표입니다. CAD에 별도 원점 (a0,b0)이 있으면 원본에서 먼저 차감합니다. m는 s=1, mm는 s=0.001입니다. +선수=(1,0), +선미=(−1,0), +좌현=(0,1), +우현=(0,−1)입니다. 다른 회전각의 CAD는 확인된 축 벡터를 사용하며 90°로 강제하지 않습니다.

### CAD 입력

- 파일·리비전, 평면/전개도 여부, 단위, CAD 기준점 좌표, 그 점의 ACS 위치, 두 축 증가 방향을 기록합니다.
- ACS의 선수 방향으로 움직이는 두 CAD 점을 비교하여 어느 축이 증가하는지 확인합니다. 좌현 방향도 별도로 확인합니다.
- 실제 한 구간의 길이를 비교하여 단위·축척을 확인합니다.
- 전개도/경사면 도면은 물리적 위치로 변환한 후 평면 X/Y를 추출합니다.

9/8 기록의 CAD +Y=선수, +X=우현과 중심 (8.64,15.48)이 맞고 ACS 중심이 (Ox,Oy)라면:
X=Ox+(CAD_Y−15.48), Y=Oy−(CAD_X−8.64).
이 값들은 해당 도면에서만 사용합니다. 다른 도면에 상수나 축 관계를 복사하지 않습니다.

### 줄자 입력

- 재현 가능한 현장 마크를 원점으로 정하고 그 마크의 ACS 위치를 먼저 결정합니다.
- “기준점에서 선수 쪽 a m, 좌현 쪽 b m”처럼 두 직교 방향의 거리를 기록합니다. 대각선 한 거리로 X/Y를 결정하지 않습니다.
- 예: 해당 층의 선미·우현 기준점 O=(Ox−L/2, Oy−W(z)/2)에서 선수 a, 좌현 b를 측정했다면 X=Ox−L/2+a, Y=Oy−W(z)/2+b입니다. 실제 표식이 그 경계점과 같을 때만 이 식을 사용합니다.
- 도면 치수와 실측 치수가 다르면 차이를 기록하고 기준 형상을 먼저 확정합니다. 오차를 숨기려고 점마다 원점이나 축척을 바꾸지 않습니다.

## 5. 기준점 선정과 캡처

1. 최소 3개의 비일직선 점, 권장 4개 이상의 넓게 분산된 점을 사용합니다. 현재 프로그램은 2점부터 계산하지만 본 절차의 방향 검증에는 부족합니다.
2. 계산에 쓰지 않을 독립 검증점을 별도로 1개 이상 확보합니다.
3. 각 점에 ID·현장 위치명·사진/도면 표시를 붙입니다. 실제 좌표와 맞지 않는 선수/선미 호칭은 정정합니다.
4. 줄자로 측정하는 로봇 기준점과 AMR 보고 pose의 기준점을 일치시킵니다. 차체 모서리와 보고 기준점이 다르면 차체 기준 오프셋을 현재 자세로 회전해 보정하거나 정해진 동일 자세로 측정합니다.
5. 로봇을 기준점에 정차시키고 해당 mapId 보고와 위치 안정 상태를 확인합니다.
6. 계획 → T_W_D 캘리브레이션에서 **정규화한 ACS 도면 X/Y와 단위**를 입력합니다.
7. **현재 위치 캡처**로 AMR 맵 X/Y(m)를 가져옵니다. 원본 보고값을 기록한 뒤 필요한 경우 수정 사유와 수정값을 함께 남깁니다.
8. **기준점 저장**을 누릅니다. 같은 물리적 점의 위치쌍인지 검토합니다. 이동 후 과거 캡처값으로 저장하지 않습니다.
9. 다른 기준점에서 반복합니다. 미검증 위치나 로봇이 다른 층을 보고하는 상태에서 수동값을 추측해 입력하지 않습니다.

기록 양식:

| 점 ID / 위치명 | 출처·리비전 | 원본 a,b / 단위 | ACS X,Y(m) | AMR 원본 X,Y(m) | 수정 X,Y·사유 | mapId/버전·시각·로봇 | 계산/검증 |
|---|---|---|---|---|---|---|---|
| P1 | CAD 또는 실측 |  |  |  |  |  | 계산 |
| V1 | 독립 측정 |  |  |  |  |  | 검증 |

## 6. 계산 전 검사와 계산

- 동일한 점 쌍의 ACS 거리와 AMR 거리를 비교합니다. 일정한 1000배 차이는 단위를, 특정 점만 다른 경우는 대응 오류나 측정을 확인합니다.
- 세 점의 순서를 고정해 삼각형의 회전 방향을 비교합니다. 반대이면 축 반사나 점 순서 오류를 확인합니다. 거의 일직선이면 판단하지 않습니다.
- 위치명을 통해 X−Ox, Y−Oy 부호를 확인합니다.
- 기존 잘못된 기준점과 새 좌표계 기준점을 섞지 않습니다. 백업 후 대상 mapId/버전의 점을 정리합니다.
- 현재 **계산(solve)은 결과를 즉시 DB에 저장**합니다. 별도 미리보기/승인 단계는 없습니다.
- tx/ty/yaw, RMS, 최대 오차, 점 수를 기록합니다. 기본 RMS 경고값 0.05m는 설정 가능하며 경고가 떠도 저장됩니다. 이는 운전 합격 기준이나 자동 차단 기능이 아닙니다.

작은 RMS만으로 축 정의가 올바르다고 판단하지 않습니다. 전체 기준점이 일관되게 90° 돌아가 있으면 잘못된 프레임에서도 RMS는 작게 나올 수 있습니다.

## 7. 적용 후 독립 검증

1. 운영 화면이 새 캘리브레이션을 읽도록 Desktop을 재시작하고 프로젝트를 불러옵니다. 현재 TankViewModel은 맵별 변환을 캐시하며 계획 화면 solve와 자동 연동해 갱신하는 경로는 확인되지 않습니다. 단순 층 선택만으로 갱신됐다고 가정하지 않습니다.
2. 독립 검증점에 로봇을 놓고 물리적 위치·ACS 표시·AMR 보고를 비교합니다.
3. 선수 쪽 이동 시 ACS X가 증가하고, 좌현 쪽 이동 시 ACS Y가 증가하는지 각각 확인합니다.
4. 알려진 방향으로 정차했을 때 0° 선수, +90° 좌현 등의 방향 표시를 확인합니다. 위치 검증과 방향 검증을 분리합니다.
5. 도면 좌표 이동을 제한된 시험 구간에서 실행해 실제 정차 위치·각도를 확인합니다. 보라 목표 마커만 맞는 것은 검증 완료가 아닙니다.
6. 위치·방향 오차가 사전에 정한 허용값을 만족하는지 기록한 뒤 운전 사용 여부를 결정합니다.
7. 실패하면 해당 보정을 운전에 사용하지 않고 입력 프레임·기준점·로봇 오프셋·맵 버전·UI 캐시를 확인합니다. 이전 값 복원도 현재 맵 버전과 일치하는 백업으로 수행하고 재검증합니다.

## 8. 재작업 조건 및 자동화 범위

맵 재생성/버전 변경, 선창 원점·축·치수 변경, CAD 리비전 변경, 측정원점 변경, 로봇 보고 기준점 변경 시 기존 대응관계를 재검토하고 필요시 재캘리브레이션합니다.

**현재 지원:** AMR 좌표 캡처·수동 수정, 기준점 저장/삭제, 회전·이동 최소자승 계산 및 RMS 경고, 현재 맵 버전의 변환 조회, 도면 좌표 이동.

**추가 개발 제안:** 측정 좌표계 프로필, 단위/축 교환/부호 후보 진단, 기준점 위치명 검증, 독립점 합격 판정, 결과 미리보기·승인·이력/복원, 서버와 UI 캐시 동시 갱신. 현재 자동 감지·자동 수정 기능이 구현된 것으로 간주하지 않습니다.

좌표쌍만으로 원점·90° 방향의 의미 오류를 항상 구분할 수 없습니다. 물리적 선수/좌현 기준과 독립점으로 후보를 검증한 뒤 사람이 적용을 확정합니다.
