# 2026-09-08 개발일지

추가 문서 작업: GenerateWalls의 실제 면 위치와 DrawingTransform 순/역변환을 재확인하여 [[HD_ACS - 캘리브레이션 작업 절차서]]를 등록했습니다. Ox/Oy 예외, CAD/줄자 입력, 로봇 측정 기준점, 즉시 저장·캐시 갱신, 독립 검증을 명시했습니다. 코드·DB 변경이나 현장 시험은 수행하지 않았습니다.

## 요청과 구현

사용자 요청에 따라 계획 화면에서 AMR 현재 위치를 캡처한 뒤 맵 X/Y(m)를 직접 수정하고 기준점을 저장하는 흐름을 추가했습니다. 저장과 캡처를 분리하며 실시간 보고는 편집값을 덮어쓰지 않습니다. 층 변경 시 편집값을 초기화합니다. Desktop/WPF 입력 화면과 공용 ViewModel, API 요청·서버 저장 경로를 수정했습니다.

운영 화면(Avalonia)에는 도면 X/Y(m) 직접 입력 이동과 선택적 정차 방향(°)을 추가했습니다. 기존 클릭·방향 드래그와 같은 goto 경로를 사용합니다. 입력값의 유한성, 층 도면 정보, 바닥 범위를 검사합니다. 수동 이동 중 바닥 커서 옆에는 도면 X/Y를 소수점 둘째 자리까지 m 단위로 표시합니다.

## 검증 및 미완료

- 캘리브레이션: Desktop 및 App 빌드 성공, 경고/오류 0.
- 수동 이동: Desktop 빌드 성공, 오류 0; Telerik NuGet 취약성 조회 NU1900 경고 1.
- 실제 화면 조작, MQTT 각도 추적, 시뮬레이터·실장비 이동은 이번 변경에서 실행하지 않았습니다.
- 이전 정차각 0도 보고는 원인 미확정이며 최신 기능 추가로 해결되었다고 주장하지 않습니다.
- 커밋·배포 완료를 의미하지 않습니다.
