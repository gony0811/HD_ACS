# 결정 001 검사영역 분할

날짜: 2026-09-07 최초, **2026-09-27 개정**. 근거: 개발 대화의 사용자 지시.

## 배경

시트 한 칸씩이 아니라 여러 칸을 묶은 로봇 검사 구역을 만든다. AMR이 이동하며 구간을 작은 AREA로 나눠 검사한다 — 코봇을 좌우 측면으로 멀리 뻗으면 J5·J6 부하가 커지고 수직 강성이 약해져 촬영에 진동이 생기기 때문이다. 높이 방향 도달은 제약이 아니다(베이스 1650mm + 텔레스코픽 리프트 1000mm 이상 + 코봇 자체 도달 → 4000mm 이상).

## 확정 기준 (2026-09-27)

- **AREA 최대 크기 1440 × 1440mm** — 코봇 최대 검사 범위(top 피치 360mm의 4칸). 서버 등록 게이트(`AreaGeometry.MaxSpanM`)와 같은 값.
- **TASK 1개 = top–top 1칸** — 인접한 두 top(도면 CENTER 선) 사이 용접선 구간. 연속 TASK는 끝 top을 공유한다.
- 가로·세로 용접선 모두 포함.
- **층마다 AREA를 새로 배치**한다. AREA는 한 층 범위 안에만 둔다.
- 경사면(SL·PL·SU·PU) 포함.
- 한 TASK는 한 AREA에만 배정(중복 검사 금지).
- **교차점 처리**:
  - CROSS3(T자, 3갈래)·2갈래(L자) 교차점에 닿는 TASK는 **제거**.
  - CROSS4(十자, 4갈래) 교차점에 닿는 TASK는 **교차점당 가로 TASK 1개만** 남겨 `seamType=CROSS4`로 등록(시작·끝점은 LINE과 같은 top–top 구간). 같은 교차점의 세로 TASK는 제거. 가로 TASK가 없는 교차점만 세로 1개를 CROSS4로 유지.
  - 가로 = 면 u 방향(벽·격벽은 수평, 바닥·천장은 선체 길이 방향).

## 좌표 변환

- 도면 Steel Wall 외곽선 모서리 = ACS 면 원점(`TankGeometry.GenerateWalls` 규약). 외곽선 치수가 선창 형상 값과 0.1mm 단위로 일치.
- 10개 면 도면은 모두 선창 내부에서 본 방향(이웃 면 라벨로 확인). SL·SM·SU는 도면 좌우를 뒤집어 ACS u(선미→선수)에, T는 상하를 뒤집어 ACS v(우현→좌현)에 맞춘다.
- 경사면 도면은 **실제 경사 길이**로 그려져 있다(SL 외곽 5,625.2mm = 3,977.6 × √2). 환산하지 않았고, 경사 방향 top 피치 254.6mm는 실제 값이다 — 이전의 "254.6 = 360의 투영" 가정은 틀림.

- 선창 형상(도면 실측): L 31.785 · 바닥 폭 10.1497 · 하부 경사 높이 3.9776 · 수직벽 6.9097 · 상부 경사 높이 2.8976 (m, 45°) → H 13.785m.
- 층 범위: L1 0~3.63 / L2 3.63~6.63 / L3 6.63~10.53 / L4 10.53~13.785m (도달 제한 미지정).
- **AREA 1,276개 · TASK 7,513개 (LINE 6,976 · CROSS4 537)**.
- 교차점 제거: CROSS3 교차점 TASK 557개, CROSS4 중복(세로 등) 525개.
- 서버 등록 규칙(면 범위·1.44m·층 유도·작업 포함·ID/이름 중복)을 재현 검증해 오류 0건. 실제 앱에서 열어 보는 확인은 미수행.

## 미결

- 층 경계를 가로지르는 LINE TASK 147개 — 한 층 AREA에 넣을 수 없어 제외. 어느 층에서 검사할지 결정 필요.
- PM의 CROSS4 교차점 2개는 닿는 TASK가 없어 CROSS4 작업이 없다(측면 개구부 부근 추정).
- profileId는 임시값 `PROF-1`. sectionDxfId는 `WALL {면코드}`.
- 도면 Membrane Sheet 직선을 용접선으로 사용 — 격벽(A·F)의 400mm 미만 짧은 선 130개가 세부 형상선일 수 있어 교차점 분류에 약간의 오차 가능.
