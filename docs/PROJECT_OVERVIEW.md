# HD_ACS 프로젝트 개요

**HD현대중공업 LNG 화물창 용접검사로봇 관제 시스템**

## 1. 배경 및 목적

LNG 운반선의 멤브레인 타입 화물창(Cargo Containment System)은 얇은 주름형(corrugated) 스테인리스 멤브레인 시트를 용접하여 시공하며, 용접부의 기밀성·품질이 선박 안전에 직결되므로 전수에 가까운 정밀 검사가 요구된다. 그러나 화물창 내부는 밀폐·대형 공간으로, 검사자가 직접 이동하며 수행하는 육안·수동 검사는 시간·일관성·기록 관리·작업 안전 측면에서 한계가 있다.

본 프로젝트는 **현대 AMR 위에 협동로봇과 카메라/측정 장비를 탑재한 이동형 용접검사로봇**을 LNG 화물창에 투입하고, 이를 운영하기 위한 관제 시스템 **HD_ACS** 를 개발하는 것을 목표로 한다.

### 운용 환경 특성 (설계 제약)
- **요철 바닥**: 멤브레인 주름(corrugation)으로 인한 요철 — AMR 주행·정차 위치 정밀도에 영향
- **밀폐 공간**: GPS 불가, 무선 통신 환경 제약 가능성 (통신 방식 검토 필요)
- **표면 보호**: 멤브레인 표면 손상 방지 — 주행 경로/접촉 관련 운영 정책 필요
- **대규모 반복 검사**: 용접선 총 연장이 길어 시나리오의 체계적 분할·진행률 관리가 핵심

## 2. 시스템 구성

| 구성 요소 | 역할 |
|---|---|
| **HD_AMR (통합 운영 S/W)** | 아래 하드웨어를 모두 통합 제어 — 검사 시퀀스·자세 제어 전담. HD_ACS의 유일한 통신 상대 (VDA 5050) |
| 현대 AMR | 요철 멤브레인 바닥 위 검사 지점 간 자율 주행 (HD_AMR이 제어) |
| 협동로봇 (Cobot) | AMR 상단 장착, 검사 자세/접근 경로 (HD_AMR이 제어) |
| 카메라·측정 장비 | 용접부 촬영·정량 측정 (HD_AMR이 제어) |
| **HD_ACS** | **검사 시나리오 운영 관제 시스템 (본 프로젝트) — HD_AMR과 VDA 5050으로만 인터페이스** |

참고 — AMR 플랫폼 측 기술 구성 (ACS 범위 외, 인터페이스 설계 시 참고):
4WD 옴니휠 홀로노믹 구동 + Airless 타이어, Ouster OS0-32 3D LiDAR + 9축 IMU, FAST-LIO2 SLAM, ROS2 Humble + Nav2 (Smac Planner + MPPI), robot_localization EKF, NVIDIA Jetson AGX Orin 64GB. AMR이 ROS2 기반이므로 HD_ACS ↔ AMR 통신은 ROS2 브리지(예: rosbridge, DDS Router) 또는 REST/gRPC 게이트웨이가 유력 후보.

## 3. HD_ACS 범위 (Scope)

### 포함 (In Scope)
- 검사 시나리오 정의/편집/저장 (검사 대상, 순서, 검사 조건)
- 미션 생성 및 디스패치 (AMR 이동 + 협동로봇 검사 시퀀스 오케스트레이션)
- 실시간 통합 모니터링 (AMR/협동로봇/장비 상태, 검사 진행률)
- 검사 데이터 수집·저장·이력 관리 및 리포트
- 예외 상황 운영 정책 (재시도, 스킵, 알람)
- 운영자 UI

### 제외 (Out of Scope)
- AMR/협동로봇/검사장비의 개별 제어 일체 — HD_AMR이 통합 담당
- 검사 시퀀스 정의·자세 제어·웨이포인트 티칭 — HD_AMR 소관
- AMR 자율주행 알고리즘 자체 (SLAM, 경로계획 등)
- 용접 결함 판정 알고리즘 자체 (비전/측정 분석 모듈과 인터페이스로 연계, 내재화 여부 TBD)

## 4. 핵심 사용자 및 유스케이스

- **검사 운영자**: 시나리오 선택/실행, 진행 모니터링, 예외 대응
- **검사 엔지니어**: 시나리오 작성/수정, 검사 조건 튜닝
- **품질 관리자**: 검사 이력 조회, 리포트 확인

대표 유스케이스:
1. 운영자가 "블록 A 용접부 정기 검사" 시나리오를 실행 → 로봇이 자동으로 순회 검사 → 완료 리포트 확인
2. 검사 중 특정 지점 접근 실패 → 정책에 따라 재시도 후 스킵, 운영자에게 알람 → 잔여 검사 계속
3. 품질 관리자가 특정 용접부의 최근 3개월 검사 이력·이미지를 조회
