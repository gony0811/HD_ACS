# 10개 WALL 전체 범위 코봇 검사 후보도

사용자 확인에 따라 **1440 × 1440 mm는 AREA 한 개의 최대 크기**로만 적용했다. 카메라 도달 높이로 해석하지 않는다. 각 `WALL_*_cobot_full_coverage.dwg`는 원본 DXF를 보존한 별도 검토도이며, 같은 이름의 DXF는 재생성용 중간 산출물이다. AutoCAD for Mac 2027에서 열어 DWG 2018 형식으로 저장했다.

| WALL | AREA 후보 | 도면상 작업 조각 |
|---|---:|---:|
| A | 104 | 448 |
| B | 154 | 472 |
| F | 104 | 448 |
| PL | 132 | 332 |
| PM | 110 | 370 |
| PU | 88 | 272 |
| SL | 132 | 332 |
| SM | 110 | 354 |
| SU | 88 | 272 |
| T | 192 | 616 |

`ACS_AREA_L0`~`L3`은 층 **후보 색상**, `ACS_LINE_H/V`는 선형 작업 후보, `ACS_CROSS3/4`는 용접선 갈래 수로 판정한 교차점 후보, `ACS_VERIFY`는 현장 확인 주석이다. 원본 Top 격자와 막 시트 선은 원본 도면층에 남아 있다. AREA 좌표와 작업 조각의 매핑은 `full-coverage-summary.json`에 기록했다.

이 배치는 도면 좌표의 1440 mm 격자로 용접선 후보 전체를 덮는 **검토용**이며 AREA 개수의 최적해는 아니다. 경사면 SL·PL·SU·PU는 도면 길이와 실제 표면 길이의 변환이 확정되지 않아 세로 격자를 보수적으로 1000 mm로 두었다. 층 색상, 코봇 정차 위치에서의 접근성, CROSS3/4의 실제 판 수, 짧은 막 시트 선의 용접선 여부는 현장에서 확인해야 한다. A·F에서 기존 결정에 따라 최하단 수평선은 제외했지만 그 선에서 위로 이어지는 수직선은 포함했다.
